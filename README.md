## 🔄 HOW AGENTS WORK (THE PATTERN)

```
Every version uses the same loop:

        👤 USER
         ↓
    🤖 "What should I do?"
         ↓
    🔨 Execute tool/action
         ↓
    👁️ Check result
         ↓
    💬 Respond to user
         ↓
    💾 Learn (optional)
```

**Versions V1→V12 just add MORE tools and smarter thinking.**
