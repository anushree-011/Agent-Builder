Personal Agent Builder
Free Agentic AI Learning Project — 12 Version Progress Tracker
🎯 Goal
Build one local agent step by step. Each version adds one important Agentic AI concept. By V12, the project should become a reusable foundation for building different advanced agents.
🆓 Free Technology
☐ Python
☐ SQLite
☐ Git + GitHub
☐ Local computer/files
☐ Free/open-source Python libraries
📚 Version-by-Version Learning Plan
V1 — Basic Local Agent
Build: 
Build a simple local agent that accepts a task, understands it and responds.
Topics: 
LLM basics, prompts, context, local models, basic agent loop.
Skills: 
Python, Ollama, prompt writing, calling an LLM, handling responses.
☐ Completed

☐ Completed

☐ Completed

🏁 Final Goal
By V12, I should understand how modern AI agents are built and have my own local Agent Builder. I should be able to use it as the foundation for future agents such as a Learning Agent, Coding Agent, Document Agent, Research Agent, File Management Agent, or other custom agents.
📌 Build Rule
Finish one version before moving to the next. Keep everything free and local where possible. Do not add advanced frameworks just for the sake of using them. Understand each concept by implementing it yourself first.
